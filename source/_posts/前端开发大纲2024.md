# 前端开发大纲2024

在技术手段的的发展和用户期望的的驱动下, 前端行业在2024年以爆发的速度发展. 前端的行业的主要目标为提供高易用性, 高功能性, 和外表美观的网页服务. 
在20204有以下几种趋势在塑造未来的前端发展.

## 前端的重点领域

### 网页开发

    开发和维护网页, 包括简单的静态页面和复杂的网页端应用, 保证其美观,易用性和功能性. 主要任务为用html/css/javascript开发响应式网页, 实现搜索
    引擎优化, 提高网页性能, 维护多浏览器兼容性, 并确保遵守网络开发通用标准和可用性指导.
    主要工具: HTML, CSS, JavaScript.

### 网页应用开发

    网页应用开发注重于复杂动态的网页应用的实现,这个领域包含易用的视觉, 互动, 构造, 性能和与后端的集成. 主要任务为确保的应用的鲁棒性,可维护性和
    规模化. 除与网页开发的共同目标外还强调与后端应用的集成.
    主要工具: React, Angular, Vue.js.

### 交互开发

    交互开发聚焦于网页的美观度和易用性, 该领域集成了用户体验设计, 用户交互页面开发和系统设计. 主要任务为通过用户调查和流程图开发确保网页的交互
    符合用户直觉. 确保网页的响应式以确保用户在不同环境下的使用体验. 
    主要工具: Adobe XD, Sketch, or Figma.

### 项目测试

    项目测似主要涉及完整的严密网页功能性, 性能, 代码, 和可用性测试. 该领域在交付高可靠性和质量的项目的过程中至关重要. 主要任务为对项目进行自动
    化测试, 人工测试, 漏洞追踪, 跨平台测试, 性能测试和安全性测试. 对项目进行全方位的质量监督.
    主要工具: 测试框架: Selenium, Jest, PlayWright, and Cypress
             漏洞跟踪:  JIRA, Bugzilla, or Trello 

### 网页性能调优

    网页性能优化是前端的的特化领域,注重于网页和网页应用的优化. 网页性能极大的影响用户体验, 搜索引擎排名和网页的总体效率. 主要任务为通过检测和优
    化网页的结构来确保网页的加载和运行速度与流畅度.
    主要工具: Google Lighthouse and WebPageTest

### 网页可用性调优

    确保网页对于残障人士的可用性.
    主要工具: Web Content Accessibility Guidelines (WCAG)

## 2024 技术发展趋势

### CSS

#### Tailwind

一个包含 flex, pt-4, text-center, and rotate-90的css框架. 最广为使用的css技术.

#### StyleX

一个将css融入js的框架, 类似于React Native StyleSheet, 在编译时编译而不是运行时, 浏览器解析时会更快.

#### Linaria

类似于 StyleX

### 组件库

#### shadcn/ui

易用和可自定义的组件, 设计的组件构建在RadixUI和Tailwind CSS之上.

#### RadixUI

开源组件库, 快速开发, 易维护, 高易用性.

### HTML Streaming

减少JavaScript的使用, 并转向服务器.包括只在服务器上运行React代码，在UI渲染中不再使用JSON.更少的JavaScript, 更快的加载.

#### React Server Components

React Server Components允许你编写可以在服务器上呈现和缓存的UI. 可以只在服务器上运行特定于组件的逻辑，如数据获取或数据库修改. 
这样可以消除不必要的客户机-服务器网络调用，以获取数据并在客户机上呈现数据。相反，您可以在服务器上执行此操作，并将HTML输出直接流
式传输到浏览器。这是React生态系统的一个巨大改进.

### HTMX

HTML允许直接在HTML中访问AJAX、CSS过渡、WebSockets和服务器发送事件，使用属性，这样就可以用超文本的简单性和强大功能构建现代用户界面。

你可以在React Server组件中获得同样的HTML流的好处，但是在任何你想使用的语言中。

HTML是一种提升版HTML，可以在单击按钮直接发出HTTP请求，或者只替换HTML的一部分而不是整个文档.

### React 的备选项

出去React, Vue, Angular 一些其他框架也在最近展露头角, 例如 htmx, Svetle, Million

### 微前端

将前端的功能开发分类然后分发到独立的团队, 团队的任务是跨端的, 从数据库到用户.

#### Module Federation

Module Federation 是Webpack、Vite/Rollup和Snowpack提供的一项强大功能，它允许在应用程序之间动态加载和共享JavaScript模.。通过将微前端与模块联合相结合，我们可以创建一个分布式架构，其中模块可以按需加载，根据需要共享资源和依赖项。

### Monorepo

随着微前端和HTML流（包括在服务器上做更多的工作）的普及，人们偏好更频繁地将代码保存在一个存储库中.这就是为什么Monoorepos也更频繁地成为首选解决方案的原因.

#### Turborepo

Turborepo是一个针对JavaScript和TypeScript代码库进行优化的智能构建系.

#### NX

NX是一个内置工具和高级CI功能的构建系统.它可以帮助您在本地和CI上维护和扩展单节点.

### State Management

长期存在的Redux基本上已经弃用了，至少在React生态系统中是这样。仍然有很多Redux项目，但它们很可能是较老的项目。
尽管Redux模式在大型应用程序中是强大且可预测的，但在中小型项目中它们通常过于复杂并且需要太多的样板。这就是为什么人们开始使用一些更轻量级的替代品。

#### Zustand

一个小型、快速、可伸缩的基础的状态管理解决方案. Zustand有一个基于钩子的简单的API.它不古板，且有足够的惯例来使其变得明确和flux-like.

#### Jotai

Jotai采用原子化地方法进行全局React状态管理。
通过组合原子构建状态，并渲染方式会参照原子间相互依赖地方式自动优化。这解决了React上下文的额外重新渲染问题，消除了对记忆的需要，并在维护声明性编程模型的同时提供了与singals相似的开发人员体验。

### API

下一个越来越流行的趋势是如何处理网络通信。正如我上面提到的，我们更经常地转向服务器。这就是为什么像tRPC/gRPC这样的模式在这里开始发光。它们的优势很明显

+ Simple
+ Type safe
+ Always synchronized
+ Self-documented
+ IDE autocomplete

#### tRPC

RPC是"Remote Procedure Call"的缩写, 它是一种从一台电脑(服务器)call另一台电脑(客户端)的function的方式. 用传统HTTP/REST APIs形式来call或者回复.

#### gRPC

gPRC 是一种高性能,开源能运行在任何环境的RPC框架. 它可以高效地连接数据中心内和跨数据中心的服务，支持负载平衡、跟踪、运行状况检查和身份验证.

### 静态网页

在本节中，我特别希望您密切关注Astro框架。它普及了一种名为“岛屿”的前端架构，对于营销网站、内容发布、文档网站、博客、投资组合、登陆页面和电子商务网站等网站来说，它非常棒。简单、快速、文档齐全——这些都是我们在复杂的前端生态系统中所需要的.

#### Next

Next.js是一个用于构建全栈web应用的React框架。使用React Components构建用户界面，使用Next.js进行附加功能和优化.

#### Astro

Astro是一个web框架，用于构建内容驱动的网站，如博客、营销和电子商务.
Astro最著名的是开创了一种新的前端架构，与其他框架相比，它可以减少JavaScript开销和复杂性. 如果你需要一个网站，加载速度快，有很好的搜索引擎优化，那么Astro就是最佳选.
